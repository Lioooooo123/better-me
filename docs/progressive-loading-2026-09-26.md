# 技能入口与渐进式加载整理：2026-09-26

默认安装从 28 个顶层入口收拢到 19 个。10 个原有专用技能保留为模块，由相关入口按任务读取；新增一个 `lark` 入口统一选择飞书对象。其余短小且有独立触发条件的技能继续保留。没有删除原有领域参考、脚本或许可文件。

| 顶层入口 | 按需模块 | 何时读取 |
|---|---|---|
| `lark` | `lark-calendar`、`lark-doc`、`lark-drive`、`lark-im`、`lark-task`、`lark-wiki`、`lark-shared` | 先按日程、正文、文件、消息、任务、Wiki 选一个模块；认证或 token 疑问才读 shared，跨服务时再读第二个。 |
| `ui` | `better-ui`、`ios-hig-design` | 精修界面细节或处理 iOS 原生体验时读取；普通界面实现只读 `ui`。 |
| `check` | `improve-react` | React 专项审查时读取；规则再按正确性、性能、无障碍、安全或可维护性选择。计划模板仅在请求计划时读取。 |

模块各自的入口改为 `MODULE.md`，参考文件仍在 `skills/<parent>/modules/<name>/`；飞书模块作为同级目录移动，跨模块相对链接已同步更新。顶层每个技能包仅有一个 `SKILL.md`，避免嵌套模块被发现为独立技能。上游映射仍记录各模块的真实来源路径，`make upstream` 可以继续逐目录比较。`catalog/skills.json` 是安装入口，`catalog/modules.json` 是保留模块。

整理前 28 个入口的 `SKILL.md` 合计 63,139 字节；整理后 19 个顶层入口合计 31,284 字节，10 个模块入口另为 18,696 字节。这是文件体积和可发现入口数量，不是实际模型上下文、token 消耗或任务成功率测量。原 `better-ui` 和 `improve-react` 的长入口已缩短；详细配方和 React 审查类别按需留在参考中。

安装器按顶层清单核对当前仓库管理的链接。退役入口只撤下符号链接并移除本仓库对应锁项，保留既有备份与恢复日志；以后在清单中重新启用时可以复用原备份。没有修改系统技能、插件缓存或不相关的安装记录。

`make check` 通过元数据、依赖、相对链接与 25 项脚本测试；`lark`、`ui`、`check` 入口分别通过 `quick_validate.py`。`make upstream` 仍报告 8 个仓库和 26 个已追踪目录 `unchanged`，新路由为本地项。本机安装状态为 19 个入口、0 个待处理动作；锁记录、符号链接与日志逐项一致，10 个模块入口均为 `MODULE.md`。这些检查不替代真实任务中的技能选择验证。
