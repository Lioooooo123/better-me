# 命令行抓取

在当前技能目录中使用 `bash scripts/fetch.sh URL`，或解析技能实际路径后调用。默认只向 URL 的源站发送请求，先使用可用正文提取库，否则回退到标准库 HTML 提取。不会因为缺可选库自动安装依赖。

输出中的 `[fetch] tier=... status=...` 是抓取状态，不是内容正确性证明。空结果、认证页或严重缺失时改用已有浏览器/连接器，不重复同一失败请求。

`--use-proxy` 是显式选项，顺序为直连、defuddle.md、r.jina.ai。第三方可能记录或缓存 URL；只用于符合任务授权的公开非敏感链接。不要把 URL 中的凭证、私有文档 ID 或内网地址发给代理。

飞书沿用现有 `lark-cli` 身份与 `lark-doc` 获取内容，不为了阅读要求用户提供应用密钥。微信、X 等动态页面优先实际可用浏览器；没有可靠可读内容时说明获取限制。

对 PDF 使用对应提取工具并按需要检查页面。脚本的普通 HTML 输出不应被当成 PDF 文本或准确布局。
