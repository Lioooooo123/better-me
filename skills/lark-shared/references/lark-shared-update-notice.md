# 版本和技能更新

本 Hub 保留的 CLI 合同基于本机 1.0.92 快照。具体命令以当前 help/schema 为准，出现 notice 不等于本次业务失败。

仅在用户要求升级或版本问题实际阻断任务时处理更新。CLI 的更新机制可能同时更新 AI Skills；不要直接对 Hub 管理的软链接运行技能覆盖更新。

更新技能应在临时独立目录获取上游版本，比较 API 合同与个人补丁，修改 Hub 源码并运行验证，再通过 Hub 安装程序更新链接。保留来源版本和内容哈希，不把上游更新当成重新部署全部技能。

认证 notice 按实际身份和缺失 scope 处理，不因为存在新版就重新登录或扩大权限。
