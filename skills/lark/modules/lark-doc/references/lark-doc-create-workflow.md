# 复杂文档创作

仅在长文、多种内容块或明确排版要求时使用此流程。已有完整内容或简单草稿直接参照 [create](lark-doc-create.md) 或 [update](lark-doc-update.md)。

复用受众、目标、事实与已批准提纲；已有足够材料时直接形成内容，不重复请用户确认体裁或样式。需要写作支持时使用 write，事实研究使用 learn。

根据真实信息关系选择段落、列表、表格和确有帮助的图片。没有统一图片配额、字数卡片或展示决策 JSON 的要求。模板与 genre 资料只有明确需要时才检索，不默认全部加载。

按相应 XML 合同构造本地内容，使用 [script](lark-doc-script.md) 解析/诊断实际支持的格式，修正无效块后创建或更新。工具命令以当前 help 为准。

在同一文档中处理已创建资源；已有画板 token 不重建替代。画板能力需要时参照 [画板](lark-doc-whiteboard.md)，所需服务不存在时说明缺口，不自动安装额外技能。

检查目标内容已写入并提供真实链接。分清起草完成、服务器已保存和视觉检查，不把任一阶段当成所有阶段完成。
