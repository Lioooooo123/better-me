# 精简后的按需能力

此 Hub 仅安装 doc、drive、wiki、im、calendar、task、shared 七个飞书入口。其他领域不自动恢复为技能；旧参考中的跨领域链接在此说明其边界。

若当前明确任务需要其他服务，先检查 `lark-cli <service> --help` 是否存在相应命令。已安装 CLI 能完成时读取具体 help/schema 后按原任务授权操作；缺能力就说明具体缺口，不自动安装额外 CLI、恢复技能或切换用户身份。

| 可选领域 | 处理方向 |
|---|---|
| 联系人 | 目标身份不明确时使用现有 `contact +search-user` 帮助，解析实际 ID；已知 ID 直接复用 |
| 电子表格 / Base | 导入导出仍由 drive 承担；表内数据操作需要当前 sheets/base 命令支持，不用 docx 操作模拟 |
| 原生 Markdown | 与导入成 docx 不同；检查 `markdown --help`，不要偷偷转换文档类型 |
| 会议 / 妙记 | 日程安排留 calendar；会议信息、逐字稿和妙记用当前会议服务帮助，已有 ID 不混用 |
| 画板 / OKR / 妙搭 | 嵌入块的读取不等于编辑其业务对象；缺所需工具时保留原 token，不重建替代 |
| 实时事件 | 持续订阅不属于普通历史消息读取；只有用户明确要求时选择有界执行并处理退出 |

不把这份表当通用 API 文档。具体参数和输出以所用命令的当前帮助及官方文档为准。若未来频繁使用某领域，可通过 Hub 维护流程重新引入对应技能。
