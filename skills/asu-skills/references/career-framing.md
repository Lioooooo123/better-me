# 技术经历的招聘表达

一条项目亮点通常包含具体场景、本人动作和可核对结果。例如“针对长任务中断，实现任务状态保存与恢复，并用中断重启用例验证继续执行”，比“负责先进 Agent 平台架构”更清楚。

匹配岗位时选择已有证据最强的能力：产品岗位强调问题判断与交付，开发岗位强调实现与质量，Agent 岗位强调工具、状态、上下文和验证。不能因目标岗位不同改变事实。

面试准备围绕真实选择展开：当时的限制、替代方案、失败与修改、验证方法、个人边界。不能回答的深层实现明确到自己实际负责的层次。

当用户只要一句开场白时，用匹配点和具体经历形成简短邀请，不附全量审计表；当需要深度准备时再逐项核对证据。
