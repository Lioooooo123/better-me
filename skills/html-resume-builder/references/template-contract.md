# 模板与验收

`assets/templates/<name>/resume.html` 是可编辑模板，`template-manifest.json` 描述预期字体、版式和模板状态。basic-a4 可作为默认起点，其他模板只在风格需求匹配时选择。

样例文字、头像与二维码不是用户事实。最终版本应以授权材料替换或移除；不能为了填满页面补造经历。

一页 A4 是本技能默认交付目标，用户另有要求时明确适配导出验证。可读字号、内容不重叠、不裁切和文本提取顺序比机械的留白比例更重要。导出脚本的留白参数用于诊断模板，不替代目视判断。

新模板需要正确的 manifest、可生成 PDF 的 HTML 和相应资产。先在隔离工作区验证模板本身，再测试真实内容长度。没有真实视觉验收就不声称每个模板都已达到交付质量。

用户明确选定模板时，导出可加 `--template <id>`，检查实际 HTML 的 `data-template` 标记。允许自定义 ID；未指定就不强制官方模板。身份标记不是样式完整性或内容真实性证明，仍需检查渲染结果。
