# Obsidian 笔记

解析一次目标 Vault：用户明确路径优先，其次当前工作区中的 `.obsidian/`，再次读取已设置的 `OBSIDIAN_VAULT`。个人默认可尝试 `~/Liora`，仅在其确有 `.obsidian/` 时使用；仍找不到再询问。

所有后续路径都从已解析 Vault 生成，不在命令里重新写默认路径。读取其 AGENTS.md、入口和同类笔记，沿用实际组织方式，不强制所有 Vault 都采用同一 PARA 编号或链接位置。

先用 `rg` 搜索现有内容、标题与别名，避免重复建笔记。引用已有笔记时使用正确 wikilink；不编造标题，移动/改名后检查相关链接。

写入自然的中文或用户指定语言，保留来源、技术结构与必要图片。`read` 提取结果和 `learn` 研究结论可直接复用，未证实观点不要改成既定事实。

临时下载、脚本、渲染与构建文件放在 Vault 外。笔记之外的配置或整个目录结构不随普通导入请求改动。

完成后检查创建/修改文件、关键内部链接和相关索引；仓库已有校验器时运行相称检查。只读请求只返回搜索与说明。
