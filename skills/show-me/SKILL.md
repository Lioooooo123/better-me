# 图示解释

选择能讲清当前问题的最小图示，使用实际名称、数据和已知关系。简单事实直接用文字；静态结构用 Mermaid，逻辑用伪代码，调用关系或文件职责用浅层树，已有结构的变化用 diff。

只保留与问题相关的状态、调用、边界和责任。大部分内容是新增、省略会隐藏执行顺序，或用户需要可复制示例时，展示完整的必要片段。

需要空间布局、可调参数或动态演示时，制作一个聚焦的 HTML 文件；沿用相关产品的颜色、字体和组件，兼顾窄屏。在任务交付目录保存，使用当前可用的浏览器或文件预览工具展示，返回真实产物链接。

让图示紧邻它支持的简短解释。不要为一个问题生成整套图示或额外网站。
